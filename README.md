## BearShare -- WashU Collaboration and Community Site

BearShare was made to allow students to share class resources with other students in their courses. This is intended to help reduce class resource gate-keeping, because we can all do better together in a collaborative environment.

# Tech Stack
- React/Next.js
- Tailwind CSS Styling
- Convex DB
- Clerk user auth
